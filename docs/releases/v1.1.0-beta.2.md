# 长截图 v1.1.0-beta.2

这是一次**预发布／公开试用版**，不是全面兼容性认证。Swift 原生 macOS 菜单栏长截图工具：框选正文区域，手动滚动，软件拼接已确认的内容。截图采集、拼接与保存均在本机完成；系统分享仅在你主动选择接收目标时交给该服务。

**相比 beta.1，本版新增双快捷键与松手开始**：保留 ⌃⌥S 的调整后确认，新增 ⌃⌥⇧S 拖完松手即开始；两项可独立设置。另减少匹配暂停时相同失败画面的重复运算。不占用系统 ⌘⇧4，不降低拼接安全校验，也不增加权限。原 beta.1 与 v1.0.0 正式版继续保留，不覆盖旧安装包。

同时包含此前的横向长截图、横纵自动识别、匹配恢复、自动续张、分段导出与原生分享。

## 下载哪个文件？

- **`LongCapture-1.1.0-beta.2-macOS-arm64.zip`**：适用于 Apple Silicon（M 系列芯片）Mac，**不支持 Intel Mac**。
- **`SHA256SUMS.txt`**：上述 ZIP 的 SHA-256 校验值。
- GitHub 自动生成的 **Source code** 是源码，不是可直接安装的 App。

部署目标为 **macOS 14+**；本次构建与验证环境为 Apple Silicon、macOS 27.2、Xcode 27.1。macOS 14/15、Intel 与真实多显示器尚未完成真机验收，部署目标不等于所有系统实测通过。安装包内部版本为 **1.1.0（build 3）**；发布标签为 `v1.1.0-beta.2`。

## 主要更新

- **双快捷键（本版新增）**：⌃⌥S 为调整模式，框选后移动／缩放选区，Return 开始；⌃⌥⇧S 为快速模式，拖选松手即开始，没有确认按钮或调整手柄。Esc 取消，单击／过小选区不会启动，可重新拖选。采集中按任一截图快捷键都完成；有待处理结果时，两者只打开现有结果。
- **独立配置与旧设置兼容（本版新增）**：设置 → 全局快捷键分别修改两项，禁止相同组合，录入时暂停两个热键；注册失败只影响对应热键，菜单仍可用。原自定义组合保留；若与快速默认组合冲突，快速热键显示「未设置」，另选组合即可，菜单快速入口不受影响。
- **选区输入修正（本版新增）**：使用最终松手坐标，防止拖动尚未结束或迟到事件重复启动；Retina 像素尺寸与实际向外对齐的采集范围一致。
- **暂停时性能优化（本版新增）**：完全相同的失败画面不再每帧重复执行 Vision 配准／历史恢复，任意像素或尺寸变化后立即重试。仅缓存整帧指纹，不增加一个视口的像素内存，不放宽匹配或接缝标准。本机合成核心探针的单帧 CPU 时间约由 51–102ms 降至 2–3ms；这不是完整 App 的 CPU 保证，也不表示用户报告的纯待机高占用已经定位。

- **横纵自动识别**：无需切换方向，首次可靠滚动自动锁定横轴或纵轴。反向回看不删除或重复加入已采内容；同一次采集不支持横纵混合拼接。
- **更好的匹配与恢复**：改善图片、短横向选区、Retina 量化差异、稀疏文字／图案和部分画廊视差场景。暂停时可查看最后确认画面；回到当前张已确认内容中能够唯一定位的位置即可恢复，不必精确退回最后一帧。
- **固定表格边缘**：自动识别滚动方向边缘的稳定表头、首列或对应的另一侧固定栏，以正文确认位移，每张图在外边缘保留一次；不是任意二维表格重建。
- **自动续张**：每张达到 6,400 万像素或滚动轴 50,000 像素长度后接到下一张，保留相邻重叠。预览按阅读顺序切换，保存／完成／普通关闭会保存整组。
- **分段导出**：将原图另存为有重叠的短 PNG，可设置分段长度和重叠；不缩放像素，也不替代原图保存。
- **拖出与原生分享**：缩略图可拖出首张、预览可拖出当前张的原始像素 PNG 副本；顶部「分享」打开 macOS 系统分享菜单。拖动暂停自动保存倒计时，结束后恢复剩余时间，原结果不会被消费或丢弃。

## 安装或更新

1. 下载 ZIP 并解压，得到 `LongCapture.app`。
2. 如果旧版正在运行，先保存／丢弃未处理的截图，再从菜单栏**退出**。然后将新版拖入 Finder 的**应用程序（Applications）**文件夹，确认替换旧版。不要在仍有未保存结果时直接覆盖正在运行的 App。
3. 从应用程序文件夹打开 App。它**常驻菜单栏，没有普通主窗口**；请找菜单栏的虚线矩形图标。
4. 按 **⌃⌥S（Control + Option + S）** 进入调整模式，或按 **⌃⌥⇧S（Control + Option + Shift + S）** 进入松手开始的快速模式；菜单栏也有对应入口。首次使用时允许屏幕录制权限；系统要求重开时，退出再启动。
5. 要开机登录时启动，在菜单栏 → **设置 → 通用 → 登录时启动**开启。先确定 App 的安装位置；移动后请重新检查该设置。不会因更新而代你开启登录项。

### macOS 阻止打开怎么办？

**本版未公证，使用 Apple Development 证书签名，不是 Developer ID 公证分发包。** 从网络下载后，Gatekeeper 可能阻止启动或提示无法检查是否包含恶意软件。签名完整性通过不代表 Apple 已审查或批准本 App。

仅在确认安装包来自本仓库并愿意信任它时操作：

1. 先从“应用程序”打开一次 App，关闭系统警告。
2. 打开 **系统设置 → 隐私与安全性**，找到刚才对长截图的拦截提示，点击 **仍要打开／Open Anyway**；不同系统措辞可能不同。
3. 按系统要求确认并验证身份，再打开 App。

**不要全局关闭 Gatekeeper 或其他系统安全机制。** 如果系统明确报告检测到恶意软件，或没有允许打开的选项，请停止安装并反馈，不要将所有安全警告都当作公证提示。尚未在另一台干净 Mac 验证首次安装，受管理设备也可能禁止运行；可选择按 README 从源码自行构建。

可将 ZIP 与 `SHA256SUMS.txt` 放在同一文件夹，在该目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

应显示 `LongCapture-1.1.0-beta.2-macOS-arm64.zip: OK`。校验值核对文件一致性，不代替安全审计或公证。

## 屏幕录制权限

唯一主动申请的隐私权限是**屏幕录制**，不需要辅助功能、输入监控或麦克风权限。保存到桌面或文稿时，系统可能额外询问文件夹访问权限。

如果开关已经允许但 App 仍显示未授权，请在菜单栏 → **屏幕录制权限…** 核对应用路径，确保授权的是 `/Applications/LongCapture.app`，而不是旧构建或“长截图（调试）”。必要时在 **系统设置 → 隐私与安全性 → 屏幕录制**（新版为“屏幕与系统录音录制”）移除旧条目、添加当前 App，再退出重开。应用不会自行重置系统授权。

## 快速使用

1. **调整模式 ⌃⌥S**：框选正文，拖动内部移动、拖边缘调整，按 **Return** 开始。**快速模式 ⌃⌥⇧S**：拖动框选，松手即开始，不再按回车；单击或过小选区可重画。两者均可按 **Esc** 取消。给滚动正文留足空间，避开无关侧栏、滚动条、输入框和持续动画。
2. 工具条准备完成后，在原应用中手动滚动，软件自动识别横纵并锁定增长方向。
3. 按任意一个截图快捷键或点击工具条**完成**。右下角缩略图约 5 秒后自动保存；悬停暂停，点击预览，按住拖动可传出 PNG 副本。
4. 预览支持滚动、缩放、复制、分享、分段导出、保存和丢弃。**复制／分享／拖出仅处理当前张；普通关闭保存整组，明确丢弃不保存。** 多张结果可通过顶部菜单切换。

默认保存到桌面，可在设置中修改保存目录和两个快捷键。不会自动改动通用剪贴板；保存失败保留结果供重试，未处理结果不被新采集覆盖。

## 已知限制与未验收项

- 双快捷键已通过隔离注册／分发、配置保留与原生窗口输入测试，但真实物理全局按键、Safari／TextEdit 中快速松手后的焦点与滚动、全屏及两个恢复默认按钮的真人操作尚未逐一验收。不把合成输入测试称作完整手势验收。
- 本次对实际运行 Release 的两轮取样未复现纯待机持续高占用。已修正的是“仍在采集、匹配暂停且失败画面未变”的重复运算路径；动态画面仍需重新匹配。完整自动化测试宿主会短时有较高负载，不能仅凭同名进程认定它是原报告的根因；排查记录见仓库 `docs/PERFORMANCE.md`。

- 完全纯色、孤立标记、真正重复的画面或无重叠快滚仍可能无法定位。不能确认时暂停，不会根据速度猜测距离或补出未知像素；回到当前张已确认的内容恢复，或结束并保存标记不完整的结果。
- 固定栏支持限于选区边缘的稳定条带，正文过小或完全重复时仍可能失败。不支持任意内部固定块、跨屏、自动滚动或同一会话二维重建。
- 部分画廊文字与底图异步运动可处理，但持续动画、视频、缩放和大面积转场仍可能暂停；文字可能保留采集时的淡化状态。不是动画消除或网页原图提取。
- **Finder／聊天软件等真实接收端的完整拖放，以及实际系统分享发送，尚未逐一人工验收。** 已验证文件承诺写盘、原始像素 PNG 与跨进程专用粘贴板；不能据此承诺所有接收应用兼容。系统分享目标可自行转换图片格式；大图首次拖出可能有编码等待。
- 自动续张与分段导出已有像素／生命周期测试，但完整生产 App 达到正式单张上限后的持续长流、多张实际分享仍需更多人工验收。
- macOS 14/15、Intel、真实多显示器、锁屏／拔屏及另一台干净 Mac 的首次安装未完成真机验收；登录项的实际批准与下一次登录启动也仍需手动检查。
- 没有崩溃恢复或历史图库。已封存续张使用私有临时文件；正常保存／丢弃会清理，强制退出或断电无法保证未保存结果可恢复。没有自动更新。
