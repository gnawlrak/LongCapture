# 长截图 v1.1.0-beta.3

这是一次**修复更新／预发布版**，不是全面兼容性认证。Swift 原生 macOS 菜单栏长截图工具：框选正文区域，手动滚动，软件拼接已确认的内容。截图处理与保存全部在本机完成。

**相比 beta.2，本版重点修复局部懒加载和局部动画造成的误暂停**。B站首页出现懒加载条带时，真实滚动位移不再被整帧配准结果带偏；页面未滚动但局部区域变化时，也不会立即把可恢复画面判成永久失败。原有重复图案、固定表头和慢滚保护继续保留。`v1.1.0-beta.2`、`beta.1` 和 `v1.0.0` 的安装包保持不动。

## 下载哪个文件？

- **`LongCapture-1.1.0-beta.3-macOS-arm64.zip`**：适用于 Apple Silicon（M 系列芯片）Mac，**不支持 Intel Mac**。
- **`SHA256SUMS.txt`**：上述 ZIP 的 SHA-256 校验值。
- GitHub 自动生成的 **Source code** 是源码，不是可直接安装的 App。

部署目标为 **macOS 14+**；本次构建与验证环境为 Apple Silicon、macOS 27.2、Xcode 27.2。macOS 14/15、Intel 与真实多显示器尚未完成真机验收。安装包内部版本为 **1.1.0（build 4）**；发布标签为 `v1.1.0-beta.3`。

## 主要更新

- **B站式懒加载修复**：局部条带更新不再把正确正文位移带偏。只有主匹配明确属于“不可靠”时才尝试有界边缘回退；重复图案产生的“歧义”结果不会被回退绕过。
- **局部动画静止判定**：只有充分分散且有纹理的区域近乎逐像素不变时，才重设参考画面；真实 `1px` 慢滚不会被误判成静止。
- **更具体的暂停原因**：采集工具条保留“匹配暂停，请往回滚动恢复”的主提示，同时显示重复图案、纹理／重叠不足、接缝失败或尺寸变化等具体原因。
- **既有功能不变**：双快捷键与松手开始、横纵自动识别、固定表头／首列、匹配恢复、自动续张、分段导出、拖出与原生分享继续可用。

## 安装或更新

1. 下载 ZIP 并解压，得到 `LongCapture.app`。
2. 如果旧版正在运行，先保存或丢弃未处理截图，再从菜单栏**退出**。将新版拖入 Finder 的**应用程序（Applications）**文件夹并替换旧版。不要在仍有未保存结果时覆盖正在运行的 App。
3. 从应用程序文件夹打开 App。它**常驻菜单栏，没有普通主窗口**；请找菜单栏的虚线矩形图标。
4. 首次使用允许**屏幕录制**权限；系统要求重开时，退出再启动。
5. 开机登录启动可在菜单栏 → **设置 → 通用 → 登录时启动**开启；移动 App 后请重新检查该设置。

### macOS 阻止打开怎么办？

**本版未公证，使用 Apple Development 证书签名，不是 Developer ID 公证分发包。** Gatekeeper 可能阻止启动或提示无法检查是否包含恶意软件。签名完整性通过不代表 Apple 已审查或批准本 App。

仅在确认安装包来自本仓库并愿意信任它时操作：

1. 先从“应用程序”打开一次 App，关闭系统警告。
2. 打开 **系统设置 → 隐私与安全性**，找到刚才对长截图的拦截提示，点击 **仍要打开／Open Anyway**；不同系统措辞可能不同。
3. 按系统要求确认并验证身份，再打开 App。

**不要全局关闭 Gatekeeper。** 如果系统明确报告恶意软件，或没有允许打开的选项，请停止安装并反馈。受管理设备也可能禁止运行；可选择按 README 从源码自行构建。

可将 ZIP 与 `SHA256SUMS.txt` 放在同一文件夹，在该目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

应显示 `LongCapture-1.1.0-beta.3-macOS-arm64.zip: OK`。

## 屏幕录制权限

唯一主动申请的隐私权限是**屏幕录制**，不需要辅助功能、输入监控或麦克风权限。保存到桌面或文稿时，系统可能额外询问文件夹访问权限。

如果开关已经允许但 App 仍显示未授权，请在菜单栏 → **屏幕录制权限…** 核对应用路径，确保授权的是 `/Applications/LongCapture.app`，而不是旧构建或“长截图（调试）”。必要时在系统设置 → 隐私与安全性 → 屏幕录制移除旧条目、添加当前 App，再退出重开。

## 快速使用

1. **调整模式 ⌃⌥S**：框选后移动或缩放选区，按 Return 开始。**快速模式 ⌃⌥⇧S**：拖完松手即开始。两者均可按 Esc 取消。
2. 工具条准备完成后，在原应用中手动滚动，软件自动识别横向或纵向并锁定增长方向。
3. 按任一截图快捷键或点击工具条**完成**。右下角缩略图约 5 秒后自动保存；悬停暂停，点击预览。
4. 预览支持滚动、缩放、复制、保存、分享、分段导出和丢弃。普通关闭会保存，明确丢弃不会保存。

默认保存到桌面，可在设置中修改保存目录和两个快捷键。保存失败会保留结果供重试，未处理结果不会被新采集覆盖。

## 已知限制与未验收项

- 本版修复的是已复现的局部懒加载条带和局部动画误判，不承诺任意 B站首页内容、无限流替换、广告变化或整页重排都可拼接。页面在一次采样间整体重排时仍会安全暂停，只保留已确认内容。
- 完全纯色、孤立标记、真正重复的画面或无重叠快滚仍可能无法定位。不能确认时暂停，不会根据速度猜测距离或补出未知像素。
- 固定栏支持限于选区边缘的稳定条带，不支持任意内部固定块、跨屏、自动滚动或同一会话二维重建。
- 持续视频、缩放和大面积转场仍可能暂停。Finder／聊天软件等真实接收端的完整拖放和系统分享发送仍需人工验收。
- macOS 14/15、Intel、真实多显示器、锁屏／拔屏及另一台干净 Mac 的首次安装未完成真机验收。没有崩溃恢复或自动更新。
