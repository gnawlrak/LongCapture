# 长截图 / LongCapture

macOS 14+ 原生菜单栏应用，Swift + AppKit + SwiftUI，无第三方运行时依赖。只做手动滚动长截图。

## 构建与启动

需要 Xcode 27 或更新版本（macOS 27 SDK）和有效的 Apple Development 签名证书，选择命令行工具后运行。运行最低版本仍为 macOS 14：

```sh
./scripts/build.sh
open build/Release/LongCapture.app
```

工程已使用本机现有开发证书，不再以临时 ad-hoc 身份交付。其他机器需在 Xcode 的 Signing & Capabilities 中选择自己的团队，或传入 `./scripts/build.sh DEVELOPMENT_TEAM=你的团队ID`。构建末尾会检查签名；没有证书时不会静默回退到临时签名。

也可打开 `LongCapture.xcodeproj`，运行共享的 `LongCapture` scheme。Debug 显示为「长截图（调试）」并使用独立标识 `com.gnawlrak.LongCapture.debug`，正式版是「长截图」和 `com.gnawlrak.LongCapture`；两者分别授权。日常使用请打开 `build/Release/LongCapture.app`。没有空白主窗口，入口在菜单栏的虚线矩形图标。

## 使用

1. 将鼠标移到要采集的显示器，按 `⌃⌥S`，或点击菜单栏 → 开始长截图。未授权时会先申请屏幕录制权限，允许后才进入框选；若系统要求重启，重新打开应用后再开始。
2. 拖动框选**正文滚动区域**。拖动内部移动，拖动边缘调整，回车开始，Esc 取消。选框不能跨屏；避开固定标题、侧栏、输入框、滚动条和动画。最小选区 24 × 24 点且不小于 96 × 64 像素。
3. 在原应用中手动缓慢滚动。选框边界完全穿透鼠标，小工具条有完成和取消按钮；再次按快捷键也可完成。
4. 首次可靠移动决定本次向上或向下增长。反向回看不会重复加入、裁掉已有内容或改变方向；回到原方向并超过已采边界后才继续增长。
5. 匹配暂停时，往回滚到最后可靠画面，再慢慢继续。此时直接完成，只导出已确认部分，并在缩略图/预览中提示不完整。
6. 结束后右下角缩略图约 5 秒自动保存；悬停暂停，移开后继续剩余时间；点击立即打开原生预览。预览支持滚动、缩放、复制、保存和丢弃；没有编辑功能。完成或普通关闭会保存，丢弃不会保存。

拼接保留可替换的增长前沿，从两帧正文重叠的内部寻找可靠接缝，不再每次直接拼入视口最上/最下的像素条带，避免直接取用边缘造成的悬浮按钮、渐变重复。最外侧仍可能保留首次/最后视口的遮挡；软件不会凭空补出从未看见的文字，也不保证消除任意固定控件。若正文重叠不足或接缝不可靠，仍会暂停并要求回滚恢复。

位移取整为 0 的画面不会替换可靠参照帧，细小移动会相对原参照累计，避免位置丢失后后续接缝持续失败。纹理与重叠校验检查相邻像素，避免规则采样恰好漏掉两像素成对图案的边缘或错位；不靠放宽误差阈值强行续接。

匹配按候选位移的实际正文重叠统计有效采样，不再因一帧滚过约半个视口就提前判为证据不足。个别 Vision 区域估计失败时，仍尝试独立的像素匹配；只有通过纹理、重叠和接缝校验才增长。相似列表会追加更密的文字边缘采样，检查不同编号等分散细节，而不是把「正文相似」直接当成「完全重复」。真正重复、重叠过少或内容变化导致无法区分时，仍保留确认部分并提示恢复，不猜测漏掉的内容。

默认保存桌面，菜单栏 → 设置中可修改目录和全局快捷键。输出原始像素 sRGB PNG，时间戳命名，同名自动递增、绝不覆盖；不自动写入剪贴板。

## 登录时启动

菜单栏 → 设置 → 通用 → **登录时启动**。默认不注册；开启后，macOS 在你登录账户时启动当前应用，只在菜单栏待命，不打开主窗口或自动开始截图。关闭开关取消后续登录启动，不退出当前应用。

使用系统 `SMAppService.mainApp`，不安装脚本、LaunchAgent 或辅助进程，也不申请新的隐私权限。开关读取系统实际注册状态，不另外存一份可能失真的偏好；在系统设置中更改后，回到应用或重新打开设置会刷新。若显示「等待系统允许」，点击「打开登录项设置」，在 macOS 的登录项面板允许；待批准时开关代表已提交的请求，仍可关闭取消。

注册/取消失败会显示原因，并保持系统实际状态，可重试。登录项绑定当前应用，开启后请保留此 App 路径；如需搬到「应用程序」文件夹，先关闭，移动后从新位置打开再开启。正式版与调试版是不同应用，分别管理。

## 原生 Liquid Glass 界面

- 选区引导、像素尺寸提示、采集工具条、结果缩略图、预览和设置统一使用系统材质。macOS 26+ 使用真正的 `NSGlassEffectView`、AppKit 玻璃按钮和 SwiftUI 玻璃按钮，不以贴图或自制模糊模拟。
- macOS 14/15 自动使用原生 `NSVisualEffectView` 毛玻璃兼容；开启「辅助功能 → 显示 → 减少透明度」时，界面背景切换为系统实色，并响应设置的实时变化。
- 窗口采用系统标题栏、圆角、字体、SF Symbols 和强调色，跟随浅色/深色外观。菜单、警告和文件选择器仍由系统直接绘制。
- 框选提示条按当前显示器的菜单栏/刘海安全区避让，并额外留出 16 点间距，不缩小可框选区域。
- 玻璃只作用于操作层，截图本身保持原始像素；采集边框继续穿透鼠标。关闭保存、明确丢弃、悬停暂停自动保存等行为不变。

## 权限与安全

- 菜单栏 → **屏幕录制权限…**，或设置 → 权限，可查看状态、点击「申请屏幕录制权限」「打开系统设置」或「检查状态」。打开应用或检查状态不会弹出授权请求；首次开始截图时若未授权，会在框选前申请。
- 拒绝后不进入框选，并提供系统设置入口。前往系统设置 → 隐私与安全性 → 屏幕录制（新版系统为「屏幕与系统录音录制」）允许「长截图」；必要时退出并重新打开应用。返回应用时自动刷新状态，只有当前进程确实获得权限后才允许截图。
- 权限页显示当前应用名称、标识和完整路径。macOS 授权与应用签名身份有关，不是只看同名开关。旧版本使用不同的临时签名，已有允许记录可能不匹配新版；若开关已打开仍无法采集，请在系统设置移除旧条目，通过 `+` 添加权限页路径指向的当前应用，再退出重开。软件不会自行修改或重置系统授权。
- 当前使用证书签名，使同一签名身份下的后续构建保持一致；更换证书、团队或 bundle ID 后仍可能需要重新授权。开发签名不等于公证或商店签名。
- 不调用辅助功能、全局输入监听、麦克风、录音或网络接口；快捷键用 Carbon 系统热键，设置录入仅监听本应用的按键。
- 屏幕流排除本应用界面和鼠标指针，只接收完整帧，后台串行匹配，最多保留一个最新待处理帧。
- 桌面/文稿属于 macOS 受保护目录；系统可能额外询问文件夹访问。这不是辅助功能或输入监控权限。保存失败时截图仍保留，可在预览选择其他目录并重试。
- 未保存或丢弃的结果阻止下一次采集；保存中禁止丢弃。退出时也会尝试保存，失败不退出。
- 输出最多 **64,000,000 像素或 50,000 像素高度**，先到者为准。达到上限、锁屏、睡眠、显示器变化或采集流中断时，安全结束并保留确认部分。

## 测试

```sh
./scripts/test.sh
./scripts/test-signing.sh
```

`swift test` 也可独立运行权限/捕获/拼接/会话的 62 项测试（不包含结果界面和登录项）；`swift test -c release` 检查优化后的核心。完整验收使用上面的 Xcode 命令，共 99 项。

XCTest 覆盖真实 Vision 配准与注入位移的逐像素拼接、上下边缘悬浮按钮/渐变不重复、向上/向下/反向回看、1–3px 慢滚、亚像素移动累计后恢复、跨多视口持续增长、55–60% 视口位移、相似编号列表/微小栅格噪声、局部及分散动态变化不得伪造匹配、纹理/重叠采样盲点、Retina/BGRA、空白/重复/动画/无重叠拒绝与恢复、无效接缝不得推进位置、精确双上限与前沿缓冲的内存边界、最新帧背压、结束尾帧、取消迟到帧、启动/结束竞态、权限申请/拒绝/外部变更/防重入/重启生效、流中断，以及缩略图计时与预览关闭/丢弃、无覆盖原子 PNG 保存、不可写目录。

签名回归需先构建 Release：拒绝临时签名；修改并重新签名一个不运行的临时副本，确认内容哈希变化而证书身份要求不变。不会更改交付 App 或 TCC 授权记录。

界面回归额外覆盖原生玻璃视图、旧版材质、减少透明度实时切换、菜单栏/刘海避让、不同顶部安全区及负坐标屏幕布局、选区移动/调整、鼠标穿透、按钮文字、键盘快捷操作、最小窗口和浅/深色布局。可生成非敏感界面样张：

```sh
./scripts/render-ui.sh
# 可选：显示测试窗口，在生成的背景上检查系统合成效果
./scripts/render-ui.sh --composited
```

样张输出到 `build/GlassUI/`。默认只做离屏布局渲染，不能据此判断完整玻璃效果。`--composited` 需要调用工具已有屏幕录制访问权，缺少时直接报错，不主动申请；它只捕获测试进程自建窗口和生成背景，明确排除其他应用。不会操作正式版、读取用户文档或改变正式版采集时的自身排除规则。

登录项测试使用注入的系统服务状态/操作；原生开关测试覆盖开启、关闭和失败回退，设置重开检查外部状态变化。样张包含关闭、待批准和注册失败三种状态。测试和样张不注册本机登录项、不打开系统设置，也不把模拟状态记为实际重启登录验收通过。

本机人工验收清单与当前验证记录见 `docs/ACCEPTANCE.md`；结构与约束见 `docs/ARCHITECTURE.md`。不要把合成帧/单元测试通过等同于 Safari、TextEdit 或微信实测通过。

## 边界

仅支持单个显示器内的单个纵向滚动区域。没有自动滚动、录屏文件、OCR、标注、云服务、图库、商店上架、公证或自动更新。移动/缩放原窗口、无重叠快滚、完全重复图案、固定栏或持续动画可能需要恢复或重新采集。完全相同的周期画面与静止在视觉上无法区分，软件保守不增长，不猜测缺失内容。

应用只在内存中保留待处理截图；正常保存/丢弃后释放。PNG 在目标目录以私有临时文件完成写入，再原子发布；保存失败时清理该临时文件。意外断电/强制结束进程不能保证恢复未保存截图。
